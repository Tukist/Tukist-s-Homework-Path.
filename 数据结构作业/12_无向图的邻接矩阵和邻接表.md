图结构

- **顶点**：a, b, c, d, e, f（共 6 个）
- **边**（共 8 条）：ab, ac, af, bc, be, cd, de, ef



## 一、邻接矩阵（Adjacency Matrix）

设顶点顺序为 a, b, c, d, e, f，邻接矩阵 A[i][j] = 1 表示有边，0 表示无边。

|     | a | b | c | d | e | f |
|-----|:-:|:-:|:-:|:-:|:-:|:-:|
| **a** | 0 | 1 | 1 | 0 | 0 | 1 |
| **b** | 1 | 0 | 1 | 0 | 1 | 0 |
| **c** | 1 | 1 | 0 | 1 | 0 | 0 |
| **d** | 0 | 0 | 1 | 0 | 1 | 0 |
| **e** | 0 | 1 | 0 | 1 | 0 | 1 |
| **f** | 1 | 0 | 0 | 0 | 1 | 0 |


> 矩阵满足对称性（无向图），主对角线全为 0（无自环）。

## 二、邻接表（Adjacency List）

| 顶点 | 邻接顶点 |
|------|----------|
| a | b, c, f |
| b | a, c, e |
| c | a, b, d |
| d | c, e |
| e | b, d, f |
| f | a, e |

链式结构示意：

```
a → b → c → f
b → a → c → e
c → a → b → d
d → c → e
e → b → d → f
f → a → e
```
